# Security Policy

## Reporting a vulnerability

Please report suspected vulnerabilities privately to `contact@sharma-raghav.com` with enough detail to reproduce the issue. Do not include credentials or sensitive personal data.

## Scope

Relevant areas include authentication, authorization, public API exposure, stored content, XSS, CSRF, injection, privacy leakage, and administrative actions.

## Safe testing

Only test systems and accounts you are authorized to test.
